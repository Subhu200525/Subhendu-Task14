# JavaScript Loops

This project is based on JavaScript loops and conditional statements.

## Task

The program performs different operations on a given number.

## Operations Performed

- Find the sum of digits of a number
- Check whether a number is an Armstrong number
- Check whether a number is a prime number
- Find all factors of a number
- Use loops and conditional statements
- Display the results using `console.log()`

## Technologies Used

- JavaScript

## Example

For the number `153`:

- Sum of digits = `9`
- Armstrong number = `Yes`
- Prime number = `No`
- Factors = `1, 3, 9, 17, 51, 153`

## Output

```text
Number :- 153
Sum of its digits: 9
Is it an Armstrong number? Yes
Is it a prime number? No
Factors: 1, 3, 9, 17, 51, 153
